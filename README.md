# paladin-for-dummies

Addon de paladín para WoW: Forever que ayuda a elegir qué sello y qué Sentencia usar según la situación.
Es un planificador y coach, no un asistente de rotación. El contexto completo está en `CLAUDE.md`.

- `addons/PalaProbe/`: sondeo de la API (fase 0).
- `docs/probe-protocol.md`: cómo instalarlo y probarlo en el juego.
- `docs/probe-results/`: resultados de cada sondeo.
- `docs/research.md`: investigación y fuentes.
